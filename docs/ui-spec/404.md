# UI spec: 404 (ES1-T244)

Mockup: `drafts/designer/ES1-T244/404.html`, PNG `404-360/768/1280/1920.png`.
Nguồn: SRS TE-9 AC2 (thông báo rõ + search + link home); DESIGN.md; Figma 1:362, 1:1104, 1:490 (card, eyebrow, h1), 1:462 link CTA, wordmark footer 1:1104. Figma không có trang 404: bố cục là ĐỀ XUẤT.

## Mục đích
Báo trang không tồn tại, cho 3 lối ra: tìm kiếm, về trang chủ, xem sản phẩm. Giữ khách ở lại bằng hàng bestseller.

## Anatomy
1. Header (dùng lại, nền trắng như `page.md`).
2. Số "404": heading font 800, uppercase, letter-spacing -0.04em, line-height 0.85, `foreground`, cỡ `clamp(7.5rem, 3rem + 18vw, 17.5rem)` (120 → 280), `aria-hidden` (lặp ý của h1). Cùng ngôn ngữ wordmark EFITCO footer. ĐỀ XUẤT.
3. Eyebrow "Error 404": heading 800 16/20 uppercase, `accent` (như eyebrow Figma 1:490).
4. h1 `'404.title' | t` "Page Not Found", `--font-size-h1`.
5. Đoạn `'404.not_found' | t`, 16/26 `muted`, tối đa 520.
6. Form tìm kiếm GET `routes.search_url`, `role="search"`: label ẩn "Search", icon search 22 trong ô, ô cao 52 viền `muted-light`, nút accent "Search" dính liền phải từ 48rem; rộng tối đa 560. Có thể gắn predictive search hiện có (TE-8).
7. Hàng hành động: `.button--secondary` "Back To Home" (`routes.root_url`) + link CTA "Shop All" (`routes.all_products_collection_url`, 28/34 + mũi tên).
8. Band sản phẩm (block `featured-collection`, Figma 1:490): eyebrow "Bestsellers", h1 "What People Are Buying?", 4 product card (snippet `product-card`): ảnh 1:1 nền `background-cream` bo 12, badge giảm giá pill `sale`, tên 16/26 500, giá sale `sale` + giá gạch 14 `muted-light`. Tabs ẩn (1 collection).
9. Footer (dùng lại).

Dữ liệu mockup (store dev): Ativafit Lava 66 lb Adjustable 379.99 / 499.99 (-24%), FlexFold Adjustable Bench 189.00 / 229.00 (-17%), Home Starter Kit 399.00 / 512.00 (-22%), Revllen Pro Speed Rope 34.99 / 44.99 (-22%). Ảnh Home Starter Kit trên store dev chưa khớp tên (ES1-T245).

## Trạng thái
- Rỗng: không chọn collection hoặc collection 0 sản phẩm → không render band sản phẩm; trang kết thúc ở hàng nút, footer theo sau (mockup Trạng thái 1).
- Lỗi: search rỗng vẫn submit được, trang search xử lý (TE-8). Không có trạng thái lỗi riêng.
- Loading: search là form GET, không loading; predictive search dùng trạng thái của TE-8. Ảnh card: nền `background-cream` giữ chỗ đúng 1:1, không layout shift.
- Hover: card ảnh scale 1.04 `--motion-base`, tên gạch chân; secondary nền 6%; link CTA gạch chân + mũi tên dịch 4; nút accent tối 12%.
- Focus-visible: outline 2px `currentColor` offset 2; ô search outline 2px `foreground` (Trạng thái 2).

- `title` trang: "Page not found – {{ shop.name }}"; HTTP 404 do Shopify.
- Số 404 `aria-hidden`; h1 là thông báo đọc được.
- Card: cả card bấm được qua `a::after` phủ, tên là link duy nhất; ảnh card `alt=""` vì tên đã là link (như snippet hiện có).
- Giá gạch có text ẩn "Regular price".
- Vùng chạm ≥ 44 cho nút, link CTA, icon header.

## Quyết định CTO cần chốt
1. Số "404" cỡ display 120–280 đen kiểu wordmark? Đề xuất: giữ, đây là điểm nhấn duy nhất, không dùng accent cho nó (accent chỉ cho hành động).
2. Nguồn sản phẩm cho band: setting collection, mặc định trống (ẩn)? Đề xuất: preset store dev chọn collection "All" sắp bestseller, theme mặc định trống để không trỏ resource không tồn tại (TE-9 AC1).
3. Nút chính là "Search" (accent), "Back To Home" secondary, "Shop All" link CTA? Đề xuất: đồng ý, một nút accent mỗi màn hình.
