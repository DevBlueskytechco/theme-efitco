`docs/merchant/<block>.md`:
```
# <Tên block>
Dùng để: 1 câu.
## Thêm vào trang (Canvas): mở Canvas → nhờ Sidekick "thêm <tên block> vào home page dưới hero" hoặc chọn block → ...
## Settings (bảng: Tên | Ý nghĩa | Mặc định) — chép đúng label từ schema
## Ảnh chụp: 1 desktop, 1 mobile (mcp__store-dev__screenshot)
## Lỗi thường gặp: resource chưa chọn, ảnh quá nhỏ, ...
## Câu hỏi hay gặp
```
Khớp 100% với schema thật; label đổi thì tài liệu đổi cùng PR.
