1 point ≈ 1 giờ dev tập trung đã có spec. Tham chiếu: block tĩnh có 4–6 setting = 3; block có ảnh + placeholder + 3 breakpoint = 4–5; JS Web Component đơn (swatch) = 3; partial cart drawer đầy đủ = 6–8; trang collection filter+sort = FE 6 + BE 6. Thêm +1 nếu chưa có Figma; +2 nếu phụ thuộc API chưa thử. Ghi giả định dưới ước lượng.
