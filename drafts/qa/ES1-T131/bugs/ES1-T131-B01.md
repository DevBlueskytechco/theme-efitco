# ES1-T131-B01 — /search tràn ngang ở mobile, view transition sang trang kết quả bị huỷ (pageerror InvalidStateError)

Mức: P2 (trang kết quả tìm kiếm cuộn ngang ở 412px; mỗi lần sang /search bằng form trên mobile có 1 lỗi JS chưa bắt trong console, mất hiệu ứng chuyển trang).
Mã bug: giả định, chưa có ticket. Ticket sửa đề xuất: ES1-T128 (blocks/search-results, thay template skeleton). Nếu ES1-T128 không thay `templates/search.liquid` thì cần ticket FE riêng.
Test: tests/e2e/ES1-T131.spec.ts "TC-02 AC1 AC2" — `test.fail` ở project mobile khi `templates/search.liquid` còn `<input ... size="50">` (tự gỡ khi template đổi).
Nguồn: docs/srs.md#TE-8 AC1, AC2; drafts/qa/ES1-T131/test-cases.md TC-02 ("0 console error"); docs/srs.md TE-6 AC12, TE-21 AC2 (trang không cuộn ngang ở 360).

Môi trường: store dev hoa-qua-nhap-khau, CI store-tests project mobile (Pixel 7, viewport 412 × 839, isMobile), Chromium Playwright 1.64.1.
Bằng chứng: run 44166815110 (e2e-mobile-1, lượt đầu + retry) và run 44095522883 đều đỏ đúng test này; desktop xanh.

Bước tái hiện:
1. Mở `/` ở Pixel 7, bấm icon tìm (`header-search-link`), overlay predictive mở.
2. Gõ `a`, Enter khi chưa chọn option.
3. Trình duyệt sang `/search?type=product,article,page&options[prefix]=last&q=a`.

Kết quả thực tế:
- pageerror `InvalidStateError: Transition was aborted because of invalid state. Viewport size changed` ngay sau khi trang mới commit, trước DOMContentLoaded (trace: sự kiện pageError t=265407, navigated t=265290).
- Trace frame-snapshot: `/` viewport 412 × 839, `/search` viewport 583 × 1188 → layout viewport bị nới vì nội dung rộng hơn 412px.
- Ảnh chụp lỗi: ô tìm của trang kết quả tràn quá mép phải.

Kết quả mong đợi: /search không cuộn ngang ở 360 và 412; chuyển trang không sinh pageerror.

Nguyên nhân:
- templates/search.liquid:5-11 — template skeleton gốc, `<input type="search" size="50">` không có class/CSS giới hạn rộng → rộng hơn khung 412px.
- Chromium mobile tính min-scale theo bề rộng nội dung, nới layout viewport (412 → 583). assets/base.css:10557 `@view-transition { navigation: auto; }` bật view transition liên trang; kích thước snapshot root của trang cũ (412) khác trang mới (583) → Chromium huỷ transition và reject promise không ai bắt → pageerror.
- Desktop không tái hiện vì ô 50 ký tự vừa khung.

Hướng sửa (FE): thay template bằng blocks/search-results (ES1-T128) hoặc tối thiểu cho ô tìm `width: 100%; max-width: 100%; box-sizing: border-box` và bỏ `size="50"`; kiểm `document.documentElement.scrollWidth <= innerWidth` ở 360, 412 trên /search.
